# GroundAct

Project website: https://groundact.github.io

Grounding What Shapes the Plan: Rethinking Groundedness for Physical Intelligence in Autonomous Driving.

## Publishing

GitHub Pages serves the root of the `main` branch. The site is plain HTML, CSS, and JavaScript; no build step is required. `.nojekyll` preserves the static assets unchanged.

## Local Preview

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## Files

- `index.html`: project content
- `script.js`: benchmark tables and page interactions
- `physical-flow.js` and `physical-flow.css`: interactive grounding-to-planning illustration
- `motion.js`: entrance animations with reduced-motion support
- `styles.css`, `theme-neutral.css`, `editorial.css`: page layout and appearance
- `assets/`: figures, logo, driving image, and paper PDF
